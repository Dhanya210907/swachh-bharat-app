# Swachh Bharat Complaint System

This is a self-contained browser prototype. It has no install step or external dependencies.

## Open the app

Open `index.html` in a modern web browser.

## Demo admin sign-in

- Email: `admin@swachh.gov.in`
- Password: `admin123`

Citizens can create a local demo profile, submit a complaint, and track its status. The admin can review all demo complaints and add status updates.

Data is stored in the browser only. This prototype is not connected to a government complaint service.
